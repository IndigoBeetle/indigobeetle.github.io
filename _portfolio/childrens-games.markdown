These games were created for a freelance client who has written a number of
children's books based on original characters. He wanted a set of puzzle games
for the promotional website. I created the games in JavaScript and HTML5,
including join-the-dots, spot-the-difference, a traditional sliding puzzle and
a maze.

Play the games [here](http://www.games.mardyboys.com/)
